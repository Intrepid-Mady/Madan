# 🐍 Python Programming Challenges

A curated collection of foundational Python programming exercises and problem-solving solutions across three progressive units.

---

## 📚 Curriculum & Unit Breakdown

### 🔹 Unit 1: Core Fundamentals & Control Flow
- **Challenge 1.1:** Implementation of recursive and iterative mathematical operations (factorial calculation).
- **Challenge 1.2:** Leap year evaluation and conditional logic testing.

### 🔹 Unit 2: Object-Oriented Programming (OOP)
- **Challenge 2.1:** Banking account operations with encapsulation, deposits, withdrawals, and balance verification.
- **Challenge 2.2:** Player and sports hierarchy demonstrating method overriding and polymorphism.

### 🔹 Unit 3: Linear Search & Sorting Algorithms
- **Challenge 3.1:** Linear search implementation for locating product instances in collections.
- **Challenge 3.2:** Student records sorting and CGPA ranking using custom comparison functions.

---

## 🚀 How to Run

Clone the repository and run any challenge script using Python 3:

```bash
# Example: Running Unit 1 Challenge 1.1
python3 "Challenge - Unit 1/Challenge 1.1.py"

# Example: Running Unit 2 Challenge 2.1
python3 "Challenge - Unit 2/Challenge 2.1.py"
```
